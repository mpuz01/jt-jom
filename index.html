Instal Aplikasi Jastip Jombang

Cara 1: Instal Langsung ke HP Android (Tanpa Play Store)

  1. Buka website Jastip Jombang ini melalui browser Google Chrome di HP Android.
  2. Ketuk ikon titik tiga (⋮) di pojok kanan atas Chrome.
  3. Pilih menu "Instal aplikasi" atau "Tambahkan ke Layar utama".
  4. Ikon aplikasi Jastip Jombang langsung terpasang di menu HP Anda dan berjalan layar penuh!

Cara 2: Ubah Jadi File Mentah (.APK) untuk Dibagikan ke Kurir

  1. Unggah file HTML website ini ke hosting gratis seperti Vercel, Netlify, atau GitHub Pages agar memiliki link HTTPS.
  2. Buka situs gratis PWABuilder.com di browser laptop.
  3. Masukkan link website Anda, lalu klik Package for Stores $\rightarrow$ Android.
  4. Unduh file JastipJombang.apk yang dihasilkan dan kirimkan lewat WhatsApp ke seluruh kurir & mitra UMKM di Jombang!
